# Moto Drive — Motorcycle Sales Website

Moto Drive is a modern promo website created for showcasing and selling motorcycles.
The design was developed manually without Figma — fully based on personal UI/UX vision, 
with a focus on clean structure, dynamic presentation, and a strong motorcycle‑themed aesthetic.


## Features
- Responsive design — full adaptation for mobile, tablet, and desktop.
- Burger menu — compact navigation for small screens.
- Motorcycle catalog — structured presentation of available bikes.
- Product cards — clear layout for each motorcycle model.
- Contact form — easy way for customers to reach the seller.
- Smooth animations — subtle transitions for better user experience.
- Optimized images — fast loading of motorcycle photos.


## Technologies
